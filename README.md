# Dil Se Dine – Restaurant Website

This is a simple restaurant website created as part of my front-end web development assignment.  
The project is built using only HTML, CSS, and JavaScript (no frameworks).

---

## Live Website
https://mansidarswal.github.io/Restaurant_web_page.github.io/

---

## About the Project
Dil Se Dine is a fictional Indian restaurant website.  
The aim of this project was to practice layout design, responsiveness, and basic JavaScript functionality like form handling, theme switching, and image interactions.

---

## Technologies Used
- HTML
- CSS
- JavaScript

---

## Features
- Responsive design for mobile, tablet, and desktop
- Light and dark mode toggle
- Sticky navigation bar with active section highlight
- Image gallery with modal view
- Customer reviews carousel
- Table reservation form
- Admin login to view user messages and reservations
- Google Maps location embed
